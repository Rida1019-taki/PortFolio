# Rida Taki — Portfolio

Personal portfolio of **Rida Taki**, Full Stack (Java / Spring Boot / React) & Mobile (Kotlin / Flutter) developer.

🌐 **Live:** [ridataki.dev](https://www.ridataki.dev)

![Portfolio preview](https://www.ridataki.dev/opengraph-image)

## Features

- Bilingual (English / Français)
- Projects, experience, education, certifications & hackathons showcases
- Interactive terminal, command palette (⌘K) and API playground
- Contact form powered by EmailJS
- SEO: Open Graph image, sitemap, robots and web manifest

## Tech stack

Next.js 16 (App Router) · React 19 · TypeScript · Tailwind CSS 4 · EmailJS · Sonner · Vercel

## Getting started

```bash
npm install
cp .env.example .env.local   # then fill in your EmailJS keys
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

### Environment variables

| Variable | Description |
| --- | --- |
| `NEXT_PUBLIC_EMAILJS_SERVICE_ID` | EmailJS service ID |
| `NEXT_PUBLIC_EMAILJS_TEMPLATE_ID` | EmailJS template ID |
| `NEXT_PUBLIC_EMAILJS_PUBLIC_KEY` | EmailJS public key |

## Scripts

- `npm run dev` — development server
- `npm run build` — production build
- `npm run lint` — ESLint
